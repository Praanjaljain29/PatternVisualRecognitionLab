# Pattern & Visual Recognition | Coursework Portfolio 👁️🤖

This repository contains my practical experiments and algorithmic implementations for the **Pattern and Visual Recognition** course. 

Completed as a **4-credit core module** during my B.Tech in Computer Science Engineering (AI & ML), this repository documents my progression from fundamental image processing to advanced computer vision techniques. 

## 📚 Academic Context
* **Course:** Pattern and Visual Recognition (4 Credits)
* **Specialization:** Artificial Intelligence & Machine Learning (AI & ML)
* **Objective:** Implementing theoretical computer vision and pattern recognition concepts using modern Python libraries, progressing from matrix-level pixel manipulation to deep learning-based visual classification.

## 🗂 Lab Implementations

The coursework is structured across 8 lab sessions. All code is documented in Jupyter Notebooks to showcase the algorithms alongside their mathematical logic and visual outputs.

* 📁 **`data/`** - Datasets, sample images, and reference files.
* 📁 **`lab1/`** - **Image Processing Fundamentals:** I/O operations, matrix manipulation, and Color Space Conversions.
* 📁 **`lab2/`** - **Filtering & Enhancements:** Implementing smoothing, sharpening, and morphological operations.
* 📁 **`lab3/`** - **Edge & Contour Detection:** Applying Canny, Sobel, and Laplacian edge detectors.
* 📁 **`lab4/`** - **Feature Extraction:** Utilizing HOG, SIFT, and SURF for robust feature matching.
* 📁 **`lab5/`** - **Pattern Classification:** Applying K-Nearest Neighbors and SVMs to visual data.
* 📁 **`lab6/`** - **Deep Learning Foundations:** Building basic neural networks for image processing.
* 📁 **`lab7/`** - **CNNs for Image Classification:** Designing Convolutional Neural Networks to classify image datasets.
* 📁 **`lab8/`** - **Advanced Object Detection:** Exploring bounding box logic and modern detection concepts.

## 🛠 Tech Stack

* **Environment:** Jupyter Notebook 📓
* **Core Libraries:** `OpenCV` (`cv2`), `NumPy`, `Pandas`, `Scikit-learn`, `TensorFlow` / `PyTorch`, `Matplotlib`
