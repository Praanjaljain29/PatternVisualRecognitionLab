# 👁️🤖 Pattern & Visual Recognition | Coursework Portfolio

This repository contains my practical experiments and algorithmic implementations for the **Pattern and Visual Recognition** course.

Completed as a **4-credit core module** during my B.Tech in Computer Science Engineering (AI & ML), this repository documents my progression from fundamental image processing techniques to advanced computer vision and deep learning applications.

## 📚 Academic Context

* **Course:** Pattern and Visual Recognition (4 Credits)
* **Specialization:** Artificial Intelligence & Machine Learning (AI & ML)
* **Objective:** To implement theoretical concepts of computer vision and pattern recognition using modern Python libraries, progressing from pixel-level image manipulation to deep learning-based visual classification.

---

## 🗂 Lab Implementations

The coursework is organized into 8 lab sessions. Each implementation is documented using Jupyter Notebooks, combining theoretical concepts, mathematical foundations, code implementations, and visual results.

### 📁 `data/`

Datasets, sample images, and reference files used throughout the experiments.

### 📁 `lab1/` — Image Processing Fundamentals

* Image I/O operations
* Pixel and matrix manipulation
* Color space conversions

### 📁 `lab2/` — Filtering & Image Enhancement

* Smoothing filters
* Sharpening techniques
* Morphological operations

### 📁 `lab3/` — Edge & Contour Detection

* Canny Edge Detection
* Sobel Operator
* Laplacian Operator
* Contour extraction

### 📁 `lab4/` — Feature Extraction

* Histogram of Oriented Gradients (HOG)
* SIFT (Scale-Invariant Feature Transform)
* SURF (Speeded-Up Robust Features)
* Feature matching techniques

### 📁 `lab5/` — Pattern Classification

* K-Nearest Neighbors (KNN)
* Support Vector Machines (SVM)
* Visual data classification

### 📁 `lab6/` — Deep Learning Foundations

* Neural network fundamentals
* Basic image processing models
* Training and evaluation workflows

### 📁 `lab7/` — CNNs for Image Classification

* Convolutional Neural Networks (CNNs)
* Image dataset classification
* Performance evaluation and visualization

### 📁 `lab8/` — Advanced Object Detection

* Bounding box concepts
* Object localization techniques
* Introduction to modern object detection frameworks

## ⚙️ Running the Notebooks

### 1. Clone the Repository

```bash
git clone https://github.com/Praanjaljain29/PatternVisualRecognitionLab.git
cd PatternVisualRecognitionLab
```

### 2. Install Dependencies

```bash
pip install numpy pandas matplotlib opencv-python scikit-learn jupyter tensorflow
```

> Install PyTorch separately according to your operating system and hardware configuration.

### 3. Launch Jupyter Notebook

```bash
jupyter notebook
```

Navigate through the lab directories and open the corresponding notebooks to explore the implementations.
