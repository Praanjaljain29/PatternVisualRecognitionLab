# Lab 1: Logistic Regression on MNIST

## Objective
Implement and evaluate logistic-regression-based classification on the MNIST handwritten digit dataset.

## Files
- `mnist_lab1.ipynb`: main notebook for preprocessing, visualization, training, and evaluation.
- `sample distribution of training &testing data.png`: distribution snapshot used in reporting.

## Dataset
The notebook uses:
- `data/mnist_train.csv`
- `data/mnist_test.csv`

Each row contains a class label and flattened pixel values for a `28 x 28` grayscale image.

## Workflow Summary
- Load train and test CSV files.
- Shuffle and split features/labels.
- Visualize sample digits.
- Train logistic-regression style classifier.
- Evaluate model predictions on test data.

## Output
- Digit sample visualizations.
- Classification performance metrics from notebook cells.

## How to Run
Open `mnist_lab1.ipynb` and run all cells in order.
