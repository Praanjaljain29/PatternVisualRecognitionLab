# Lab 7: Linear Regression from Scratch (NumPy)

## Objective
Build a linear regression model from scratch using gradient descent and evaluate it on synthetic and real datasets.

## Files
- `lab7.ipynb`: full implementation and experiments.

## Workflow Summary
- Implement a `LinearRegressionScratch` class with:
  - parameter initialization
  - gradient descent updates
  - prediction function
  - R2 scoring
- Validate implementation on synthetic data.
- Apply model to a library dataset (`California Housing` when available, with `Diabetes` fallback).
- Perform train/test split, feature scaling, and final evaluation.

## Metrics Reported
- MAE
- RMSE
- R2

## Output
- Learned weights and bias.
- Loss trend and regression quality metrics.
- Sample predictions on unseen data.

## How to Run
Open `lab7.ipynb` and run all cells.
